# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for security-sensitive findings, credentials, tokens, private customer information, or exploitable vulnerabilities.

Report security concerns directly to the repository owner or an authorized 321 DataPro technical contact using an approved private communication channel.

## Repository security rules

- Never commit passwords, API keys, tokens, certificates, or other secrets.
- Store deployment and service credentials in the appropriate protected environment or provider secret store.
- Production changes should be made through a pull request and reviewed before release.
- High-risk changes involving domains, DNS, authentication, payments, credentials, or private data require explicit human review.
